# Modèle de dépôt - nouveau projet de l'atelier archi-ingénierie (SABTP)

Dépôt **modèle** (Template) : ne pas travailler ici. Pour un nouveau projet :
1. GitHub : **New repository** -> *Repository template* = `Elzo1998/model-projet-archi`, nom du projet (ex. `babacar`).
2. Ouvrir une session Claude Code sur ce nouveau dépôt seul.
3. Écrire « nouveau projet archi » (ou décrire le projet). Claude rattache l'atelier `elzo1998/atelier-archi-ingenierie`
   et fait le reste (skill `nouveau-projet-archi`).

Le `CLAUDE.md` de ce dépôt contient la consigne de démarrage ; il est remplacé par la mémoire du projet à l'amorçage.
